## 技术架构

```
用户输入 <el- 
    ↓
UnifiedTagNameProvider.getDescriptor()
    ↓
ProviderManager.getProvider(project)
    ↓
UnifiedComponentProvider.supportsTag(tagName)
    ↓
UnifiedXmlElementDescriptor (创建元素描述符)
    ↓
IDE显示补全提示
```

## 数据流

1. **启动时**: `UnifiedPluginStartupActivity` → `ProviderManager.getProvider()` → 创建默认Element Plus库
2. **补全时**: `UnifiedTagNameProvider` → 检查标签 → 返回元素描述符
3. **管理时**: `ProviderManager` 提供重新加载、移除等功能

## 性能考虑

- **内存**: 每个项目一个Provider实例，避免重复加载
- **CPU**: 延迟加载，只在需要时创建
- **并发**: ConcurrentHashMap保证线程安全
- **异常**: 优雅处理IDE异常，不影响用户体验

## 扩展性设计

- **多库支持**: 数据模型支持多种组件库
- **动态加载**: ProviderManager支持重新加载
- **配置化**: 预留了从设置读取配置的接口
- **JSON驱动**: 数据模型与JSON格式完全对应
