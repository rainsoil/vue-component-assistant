# VueKit 配置文件说明

## 配置文件架构

VueKit 使用分层配置文件架构，每个配置文件都有明确的职责，避免信息重复和职责不清。

## 1. 本地静态配置：`library-config.json`

**位置**：`src/main/resources/data/library-config.json`

**作用**：本地组件库识别和分类的静态配置

**包含内容**：
- 组件库ID和包名映射
- 组件前缀（用于识别组件属于哪个库）
- 显示名称和描述
- 框架类型和分类
- 基础元数据

**特点**：
- 静态配置，不经常变化
- 本地文件，不依赖网络
- 用于组件库识别和分类
- 不包含动态信息
- **支持动态扩展**：可以自动发现和配置新的组件库

**使用场景**：
- 识别组件前缀（如 `el-` 属于 Element Plus）
- 组件库分类和显示
- 基础信息展示

## 2. 官方组件库市场索引：`official-library-registry.json`

**位置**：远程服务器（如 Gitee）

**作用**：官方组件库市场的索引文件

**包含内容**：
- 可用组件库列表
- 下载链接
- 版本信息
- 评分和下载量
- 框架要求
- 许可证信息

**特点**：
- 远程文件，需要网络访问
- 动态更新
- 用于组件库选择和下载

**使用场景**：
- 显示可用的组件库
- 提供下载链接
- 显示组件库的评分和统计信息

## 3. 下载后的组件库详情：`{library-name}-libraries.json`

**位置**：本地缓存目录

**作用**：下载后的组件库详细数据

**包含内容**：
- 组件的具体信息（属性、事件、插槽）
- 文档URL
- 示例代码
- 版本要求

**特点**：
- 本地缓存文件
- 包含完整的组件信息
- 用于代码补全和文档显示

**使用场景**：
- 代码补全提示
- 悬停文档显示
- 右键菜单文档
- 组件属性、事件、插槽信息

## 数据流向

1. **启动时**：加载 `library-config.json` 进行本地组件库识别
2. **自动发现**：自动发现已下载的组件库并配置识别信息
3. **用户选择**：从 `official-library-registry.json` 选择要下载的组件库
4. **下载过程**：下载组件库详情到本地缓存
5. **自动配置**：新下载的组件库自动配置识别信息
6. **运行时**：从本地缓存的组件库详情中获取组件信息

## 优势

1. **职责清晰**：每个配置文件都有明确的作用
2. **避免重复**：信息不重复，各司其职
3. **易于维护**：修改某个方面只需要修改对应的配置文件
4. **性能优化**：本地配置快速加载，远程信息按需获取
5. **扩展性好**：新增组件库只需要修改相应的配置文件
6. **自动发现**：支持自动发现和配置新的组件库，无需手动配置
7. **向后兼容**：预定义配置和新发现配置并存，确保系统稳定性

## 注意事项

1. **不要修改** `library-config.json` 中的组件前缀，这会影响组件识别
2. **定期更新** 官方组件库市场索引，获取最新的组件库信息
3. **清理缓存**：如果组件库信息过期，可以清理本地缓存重新下载
4. **版本兼容**：确保下载的组件库版本与项目要求兼容

## 总结

- `library-config.json`：本地静态配置，用于组件识别和分类
- `official-library-registry.json`：远程索引，用于组件库选择和下载
- `{library-name}-libraries.json`：本地缓存，用于代码补全和文档显示

这种分层架构确保了配置的清晰性和系统的可维护性。
