# B2 属性补全与值枚举实现说明

## 功能概述

B2实现了基于JSON数据的组件属性补全功能，包括：
- 属性名称补全
- 属性值枚举（当属性有options时）
- 属性描述显示
- 默认值提示

## 实现架构

### 1. 核心类结构

```
B2 属性补全架构
├── UnifiedXmlAttributeDescriptor.java          # 属性描述符
├── UnifiedXmlAttributeDescriptorsProvider.java # 属性描述符提供者
├── AttributeType.java                          # 属性类型枚举
└── 集成到UnifiedXmlElementDescriptor.java      # 元素描述符集成
```

### 2. 数据流

```
用户输入属性 → XmlAttributeDescriptorsProvider → 获取组件信息 → 构建属性描述符 → IDE显示补全
```

## 核心实现

### 1. 属性描述符 (UnifiedXmlAttributeDescriptor)

```java
public class UnifiedXmlAttributeDescriptor implements XmlAttributeDescriptor {
    private final String name;           // 属性名
    private final String description;    // 属性描述
    private final String[] options;      // 枚举值选项
    private final String defaultValue;   // 默认值
    private final AttributeType attributeType; // 属性类型
    
    // 关键方法
    public boolean isEnumerated() {
        return options.length > 0;  // 有选项时返回true
    }
    
    public String[] getEnumeratedValues() {
        return options;  // 返回枚举值数组
    }
}
```

### 2. 属性描述符提供者 (UnifiedXmlAttributeDescriptorsProvider)

```java
public class UnifiedXmlAttributeDescriptorsProvider implements XmlAttributeDescriptorsProvider {
    @Override
    public XmlAttributeDescriptor[] getAttributeDescriptors(@Nullable XmlTag context) {
        // 1. 获取组件提供者
        var provider = ProviderManager.getProvider(context.getProject());
        
        // 2. 获取组件信息
        Component component = provider.getComponent(context.getName());
        
        // 3. 构建属性描述符列表
        List<UnifiedXmlAttributeDescriptor> descriptors = new ArrayList<>();
        for (Prop prop : component.props) {
            descriptors.add(toDescriptor(prop));
        }
        
        return descriptors.toArray(new UnifiedXmlAttributeDescriptor[0]);
    }
    
    private UnifiedXmlAttributeDescriptor toDescriptor(Prop prop) {
        // 转换Prop为UnifiedXmlAttributeDescriptor
        String[] options = prop.options != null ? 
            prop.options.toArray(new String[0]) : new String[0];
        
        return new UnifiedXmlAttributeDescriptor(
            prop.name,
            prop.description,
            options,
            prop.defaultValue != null ? prop.defaultValue.toString() : null,
            AttributeType.PARAM
        );
    }
}
```

### 3. 属性类型枚举 (AttributeType)

```java
public enum AttributeType {
    PARAM("参数", AllIcons.Nodes.Parameter),
    EVENT("事件", AllIcons.Nodes.Event),
    SLOT("插槽", AllIcons.Nodes.Slot);
    
    private final String displayName;
    private final Icon icon;
}
```

## 数据结构支持

### JSON数据格式

```json
{
  "props": [
    {
      "name": "type",
      "type": "string",
      "description": "按钮类型",
      "defaultValue": "default",
      "required": false,
      "options": ["primary", "success", "warning", "danger", "info", "default"]
    },
    {
      "name": "size",
      "type": "string", 
      "description": "按钮尺寸",
      "defaultValue": "default",
      "required": false,
      "options": ["large", "default", "small"]
    }
  ]
}
```

### 支持的属性特性

1. **属性名称**: `name` 字段
2. **属性描述**: `description` 字段
3. **默认值**: `defaultValue` 字段
4. **是否必需**: `required` 字段
5. **枚举值**: `options` 数组
6. **属性类型**: `type` 字段

## 功能特性

### 1. 属性名称补全

- 在组件标签内输入空格时触发
- 显示该组件所有可用属性
- 包含属性描述和图标

### 2. 属性值枚举

- 当属性有 `options` 时，提供值补全
- 在属性值输入时显示可选值
- 支持字符串类型的枚举值

### 3. 属性描述显示

- 在补全列表中显示属性描述
- 悬停时显示详细描述
- 包含默认值信息

### 4. 默认值提示

- 显示属性的默认值
- 在补全建议中标注默认值

## 扩展点注册

在 `plugin.xml` 中注册属性描述符提供者：

```xml
<!-- B2: 属性补全扩展点 -->
<xml.attributeDescriptorsProvider 
    implementation="com.chu7.vuecomponentassistant.extension.UnifiedXmlAttributeDescriptorsProvider" 
    order="first"/>
```

## 集成方式

### 1. 与元素描述符集成

修改 `UnifiedXmlElementDescriptor` 使用新的属性提供者：

```java
@Override
public XmlAttributeDescriptor[] getAttributesDescriptors(@Nullable XmlTag context) {
    if (context != null) {
        var provider = new UnifiedXmlAttributeDescriptorsProvider();
        return provider.getAttributeDescriptors(context);
    }
    return new XmlAttributeDescriptor[0];
}
```

### 2. 与现有系统集成

- 复用 `ProviderManager` 获取组件数据
- 复用 `Component` 和 `Prop` 数据模型
- 保持与B1组件补全的一致性

## 已知限制

1. **类型支持**: 目前主要支持字符串类型的枚举值
2. **复杂类型**: 复杂类型（如对象、数组）的补全延后到类型化增强
3. **动态属性**: 不支持动态计算的属性值
